### 👨‍💻 Sobre mí

Técnico en **Análisis y Desarrollo de Software (SENA)** con fuerte inclinación hacia la arquitectura y lógica **Backend**. Me especializo en construir soluciones eficientes, escalables y seguras usando **Java con Spring Boot, Python y bases de datos relacionales MySQL**.

- 🔭 **Actualmente trabajando en:** Proyectos fullstack con Next.js y profundización en microservicios con Spring Boot.
- 🌱 **Especialidades:** Arquitectura MVC, diseño de esquemas relacionales, APIs RESTful, calidad de software y pruebas funcionales.
- 🤖 **Innovación:** Integración de herramientas de IA generativa y protocolos modernos como **MCP (Model Context Protocol)** para potenciar análisis y documentación técnica.
- 📍 **Ubicación:** Cúcuta, Colombia 🇨🇴
